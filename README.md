# LinkPage — your own link-in-bio page, free forever

Thanks for buying! This is a link-in-bio page (like Linktree) that **you own**.
No monthly fees, no "Made with Linktree" badge, no limits. You can host it for free.

**You only need to edit one file: `config.js`.** No coding required.

---

## 1. Personalize it (2 minutes)

1. Open `config.js` in any text editor (Notepad works, or edit it right on GitHub).
2. Change your name, bio, links, and social accounts. Keep the quotes and commas.
3. Pick a theme: `midnight`, `sunset`, `ocean`, `forest`, `candy`, `paper`, `mono`, `aurora`.
4. Add your photo: drop it into this folder (e.g. `me.jpg`) and set `avatar: "me.jpg"`.

To preview, double-click `index.html` and it opens in your browser.

## 2. Put it online for free with GitHub Pages (5 minutes)

1. Create a free account at https://github.com.
2. Click **+ → New repository**. Name it `yourusername.github.io` (use your real username), set it to **Public**, and click **Create**.
3. Click **uploading an existing file**, drag in **all** the files from this folder, and click **Commit changes**.
4. Go to **Settings → Pages**. Under "Branch," choose `main` and click **Save**.
5. Wait about a minute. Your page is live at `https://yourusername.github.io` 🎉

Paste that link into your Instagram, TikTok, YouTube, or X bio.

> **Tip:** To change links later, open `config.js` on GitHub, click the ✏️ pencil, edit, and commit. The page updates in about a minute.

### Other free hosts
- **Netlify Drop:** go to https://app.netlify.com/drop and drag this folder in.
- **Cloudflare Pages / Vercel:** connect your GitHub repo.

## 3. Use your own domain (optional)

Bought `yourname.com`? In GitHub, open **Settings → Pages → Custom domain**, type your domain, and follow the DNS instructions GitHub shows you.

## Icons

- Any brand on https://simpleicons.org works. Use the name in lowercase with no spaces, e.g. `youtube`, `patreon`, `twitch`, `onlyfans`, `substack`, `cashapp`, `venmo`, `etsy`.
- Built-in icons: `email`, `link`, `phone`, `website`, `calendar`, `cart`, `heart`.
- A few brands (for example LinkedIn) aren't on Simple Icons. Use `link` or `website` for those, or put an emoji in the button title.

## Featured link

Add `featured: true` to a link to make it stand out with a glowing pulse. It's great for a sale, a new video, or a launch.

## Click tracking (optional)

Create a free Google Analytics 4 property, copy the ID (`G-XXXXXXXXXX`), and paste it into `analyticsId`. Each button click is recorded as a `link_click` event.
